# 项目约束

本文规定指令翻译的产品行为。示例不缩小适用范围；任何实现、移植及资源修改均须同时满足这些约束。

## 英文与多语言并存

1. 原版英文命令、子命令、参数值和原始资源 ID 始终保留，不能被本地化形式替换。
2. 在每一种受支持的语言环境中，英文原版形式与该语言的本地化形式必须同时可用。这不是只针对中文的功能；中文只是示例和最低支持要求。
3. 补全列表必须保留原版候选，并额外提供对应的本地化候选。两种形式都能选择、插入和执行，不能仅在内部解析器中保留英文却从列表隐藏英文。
4. 并存规则适用于命令名、固定子命令、有限枚举值、资源 ID、标签、选择器选项、方块状态、NBT 和数据组件的键及可补全的值，不限于某条命令或截图中的项目。
5. 同一原始 ID 对应的英文候选和本地化候选是不同的显示及插入形式，不能仅按原始 ID、翻译键或底层 Suggestion 对象将两者合并。只有语义来源、显示和插入内容均一致时才可去重。
6. 关闭本地化功能后恢复原版输入及补全；任何开关状态都不能使原版英文形式失效。

```mermaid
flowchart LR
    E[原版英文候选] --> L[同一补全列表]
    T[当前语言的本地化候选] --> L
    L --> I[保留所选输入形式]
    I --> C[客户端还原原始命令与参数]
    C --> V[原版解析 权限 签名与发送]
```

## 语言与翻译资源

- 所有本地化功能使用 Minecraft 原版 I18n 和翻译键，语言随游戏语言设置变化，资源包可以覆盖或补充。
- 英文和简体中文为最低支持范围，不能将项目缩减为中英文专用。其他语言在资料与翻译可落实时尽量提供；缺少可靠资料的语言可以暂缓，不编造说明以凑齐语言数。
- 默认覆盖所支持版本中的全部原版命令，不仅是 `give`。不得把某个示例的修复当作全项目覆盖。
- 物品、方块及其他已有名称的对象优先使用模组和资源包现有的原生翻译，不能要求整合包作者为每个对象重复建立本项目词条。
- 翻译文件中的缺项按原版机制回退英文，不能因此删除英文候选或隐藏原版输入形式。

## 命名空间与重名

- 本地化名称采用 `<命名空间名称>:<名称>`，名称所在语言和命名空间名称均跟随翻译资源。命名空间没有译名时保留原始 modid。
- 中文示例：`minecraft:plains` 对应 `我的世界:平原`，`create:large_cogwheel` 对应 `机械动力:大齿轮`。这些示例不表示其他语言使用中文名称。
- 输入、补全和本地化 tooltip 使用相同的命名空间规则；标签保留 `#`，否定及其他语法标记保持原义。英文原始 ID 保持原样。
- 同一命名空间、同一语义域内出现重名时，在名称后附完整原始 ID，例如 `机械动力:大齿轮(create:large_cogwheel)`。该消歧形式也必须可输入和补全，不能任意选择其中一个对象。
- 不同注册表中的同名标签分别识别，不能把物品标签、方块标签或生物群系标签的含义混用。

## 提示与搜索

- 补全列表和输入框中已输入的命令及参数均提供悬停提示。
- 鼠标指向哪一项，就解释哪一项。命令说明作用，参数说明用途，固定选项说明其效果；资源候选优先显示真实对象名称。
- NBT、数据组件、选择器和方块状态按具体键、嵌套字段或值提供说明，不能回退成外层命令的统一教程。
- 候选值必须解释该值自身的含义，不能让同一字段下的所有候选共用字段总说明。注册表资源值、枚举、布尔值及嵌套物品数据同样适用；补全列表与已输入值共用查询规则。
- 说明、资源名称、值类型和上下文注册表绑定须提供原版语言文件扩展接口。整合包和模组可以覆盖具体值或添加新值，不要求修改 Java；具体词条优先于通用类型词条。
- 字段和值的说明应简短、具体，保留必要限制；不叠加重复段落、完整 Wiki 文章、无关版本教程和外层整条命令用法。
- 命令名称的提示同时提供简短作用和原版语法，保留必填、可选、分支及重定向标记；当前语言的命令和参数名称在对应英文语法片段上方以小字标注，英文语法不能被替换。
- 命令的相关参数使用独立的小提示框解释，参数说明不堆入同一个长段落；字段和值仍保持当前项目的简短具体说明。语法根据当前命令树生成，不为 `give` 编写专用逻辑。
- 主提示保留命令作用与语法；附属参数框使用较小字号、较窄宽度和紧凑内容，在侧边排列，不能与主框等大平铺。候选名称使用简短译名，解释文字参与搜索但不重复充当长篇候选名称。
- 同一选择器的原版简短提示与本项目说明不重复叠加；仍保留第三方提供的不同内容。
- 物品详情复用原版物品说明和属性文本，并按原版多行文本排版，不能把换行符绘成字形。有效的物品 NBT 或组件通过匹配版本的原版解析器读取。生物详情使用已注册的默认属性，默认只启用最大生命值、攻击伤害、移动速度和护甲值；其他属性保留独立开关，默认关闭。不创建世界实体，不把默认属性冒充当前实体状态，不为不存在的属性编造数值。效果提供有来源的简要说明。
- 同一资源名称不因一侧附带原始 ID 消歧后缀而在提示中重复，消歧后缀必须保留；第三方真正不同的补充内容仍保留。
- 原版及 Loader 基础标签提供各自含义，不使用统一的“这是某类参数”代替具体说明。
- 当前语言的名称、别名及有明确对应关系的说明应参与候选筛选。完整且唯一的本地化形式可还原为原始项，说明片段仅用于搜索，歧义不得猜选。
- 已有原版和第三方补全提示、动态回调及必要元数据必须保留，不得以本项目说明覆盖其能力。

## 资料来源

- 原版命令、参数、组件、NBT 和标签的含义来自 Minecraft Wiki，保留具体页面及修订等来源信息。
- Loader 基础标签缺少 Minecraft Wiki 说明时，可以使用 Forge、NeoForge、Fabric 的官方文档、官方资源或官方源码中的明确说明。
- 不能根据英文名称、相似条目或未核实的版本经验编造用途。对象显示名称复用原生翻译，不等于可以自行编写其语义。
- 运行时使用随包说明和语言资源，不依赖在线 Wiki 请求。

## 客户端与补全链路

- 仅客户端安装即可连接原版服务器。本地化形式在客户端还原，服务端收到原始命令及参数。
- 保留原版解析、权限、命令重定向、聊天签名、网络顺序、补全提供者回调和副作用，不实现另一套服务器命令语义。
- 玩家名、坐标、聊天正文及任意自定义数据保持原义；只有实际命令上下文中可确认的本地化项才参与还原。
- 保留 Identifier Translation 的功能；NBT Autocomplete 随包提供 NBT 和组件键、嵌套字段及值补全，其独立设置和完整功能不得被禁用。
- 使用实际版本及 Loader 支持的 API 和变换范围。不能以编译成功代替运行接入，也不能依赖不会经过相应 Loader 变换的库类 Mixin。

## 配置开关

功能总开关默认开启并可手动通过 `config/command_translation.json` 关闭；生物逐属性开关采用上述精简默认值。总开关之外，本地化输入、译名、说明搜索、用法说明、补全悬停、已输入内容悬停、英文语法、小字标注、参数框、紧凑参数框、结构化字段、值说明、标签说明、物品详情、生物详情和效果简介分别设置。原版英文输入和第三方原有能力不因关闭本项目的提示而失效。NBT Autocomplete 的完整补全及其独立配置保持不变。
